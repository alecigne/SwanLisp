* =nearley.js=
:PROPERTIES:
:CREATED:  [2025-12-28 Sun 13:40]
:END:

Here's a Nearley version of the Polish Notation Grammar:

#+begin_example
  lispy -> operator " " expr (" " expr):*
  expr  -> number | "(" operator " " expr ( _ expr ):* ")"
  operator -> "+" | "-" | "*" | "/"
  number -> "-":? [0-9]:+
#+end_example

This grammar parses examples from the book successfully:

#+begin_example
  + 1 2 6
  + 6 (* 2 9)
  / (* 10 2) (+ 4 2)
  + 5 (* 2 2)
#+end_example

...and doesn't parse the wrong inputs. It can also generate data:

#+begin_example
  - 2
  / 94 2978 (- -5)
  ,* -960 -0 741 5 -1
#+end_example

...that the C parser can parse.
