#+title: SwanLisp

SwanLisp is a Lisp written in C. It is my personal repo for the [[https://www.buildyourownlisp.com/][Build
Your Own Lisp]] book.

* Compilation
:PROPERTIES:
:CREATED:  [2025-12-11 Thu 19:13]
:END:

Without debugging:

#+begin_src sh
  cc -std=c99 -Wall program.c -o program
#+end_src

With debugging:

#+begin_src sh
  cc -std=c99 -Wall -g -O0 program.c -o program
  gdb program
#+end_src
